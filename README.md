# 龙甲・长坂战域

三国人形机甲单页游戏。玩家驾驶赵云「白龙」，以键盘或战场内的鼠标控制台移动、攻击、牵引倒地机甲，并在三方营地的战斗中推进。

## 运行

直接用浏览器打开 `mech-three-kingdoms.html`。

## 鼠标与键盘操作

- 方向键：移动赵云；鼠标按住战场右下角方向键可持续移动，单击可移动一小步。
- `1` 攻击、`2` 防御、`3` 拔剑、`4` 射箭。
- 按住 `5` 加速，最多 20 秒。
- `6` 后按 `Q/W/E/R/T`，牵引对应的一台倒地机甲。

## macOS 独立应用

在 macOS 中运行：

```zsh
./macos-app/build-macos-app.sh
```

会在项目根目录生成 `龙甲・长坂战域.app`。
